# BEQUEM — Interactive Client Concept V12

Client-facing concept for BEQUEM Men & Women. Includes the **ON THE RAIL** interaction, **Build Your Look** with corrected product cards and swipeable variants, New Drops, and a product-page concept. All products/prices are illustrative and checkout is not connected to Shopify.

## Publish to GitHub Pages

This folder is prepared for the **MichaelDaniel-dev/bequem-website** repository. Upload `index.html`, `assets/` (the full folder), `README.md` and `.nojekyll` into the **repository root**. Do not upload this ZIP as one file.

Then open **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Wait for Pages to finish publishing, then test the URL from an incognito browser. Expected URL (only after a successful deployment): `https://michaeldaniel-dev.github.io/bequem-website/`.

If you prefer the command line, extract this ZIP and run in an empty local checkout of the repository:

```sh
git add .
git commit -m "Publish BEQUEM client preview V12"
git push origin main
```

No payment, inventory, actual product catalogue or personal customer data is included.
